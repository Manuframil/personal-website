# Manuel Framil

Web personal con experiencia, proyectos seleccionados y publicaciones.
HTML y CSS sin dependencias ni paso de compilación.

## Desarrollo local

Abre `index.html` en el navegador o sirve la carpeta con Python 3:

```sh
python3 -m http.server 8000
```

Visita <http://localhost:8000>.

## Archivos

- `index.html`: contenido y estilos de la web.
- `favicon.svg`: icono con las iniciales MF.

Para publicar, sirve ambos archivos desde cualquier alojamiento estático.
